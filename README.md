# bip158

Isomorphic [BIP-158](https://github.com/bitcoin/bips/blob/master/bip-0158.mediawiki) compact block filters (GCS) for TypeScript. Runs in Node, Bun, browsers, and React Native (Metro resolves the `react-native` export).

## Use from a checkout

This implementation is currently unpublished and marked private. The registry name `bip158` belongs to another project, so `bun add bip158` and `npm install bip158` do not install this code.

Clone or otherwise check out this repository, then install it:

```bash
cd /path/to/bip158
bun install
```

Use the checkout from another local project by passing its path:

```bash
bun add /path/to/bip158
# or
npm install /path/to/bip158
```

## Example

```ts
import {
  buildBasicFilter,
  bytesToHex,
  hexToBytes,
  matchAnyBasicFilters,
} from "bip158";

// Testnet genesis (official BIP-158 test vector, height 0).
const blockHashDisplay = hexToBytes(
  "000000000933ea01ad0ee984209779baaec3ced90fa3f408719526f8d77f4943",
);
const coinbaseScript = hexToBytes(
  "4104678afdb0fe5548271967f1a67130b7105cd6a828e03909a67962e0ea1f61deb649f6bc3f4cef38c4f35504e51ec112de5c384df7ba0b8d578a4c702b6bf11d5fac",
);

const filterBytes = buildBasicFilter({
  blockHashDisplay,
  elements: [coinbaseScript],
});
console.log(bytesToHex(filterBytes)); // 019dfca8

console.log(
  matchAnyBasicFilters([filterBytes], [blockHashDisplay], [coinbaseScript]),
); // [true]
```

### Block hash and filter header endianness

RPC and explorer block hashes — and the official BIP-158 test vectors — use **display order** (byte-reversed relative to Bitcoin’s internal little-endian representation). Pass display-order hashes to `buildBasicFilter` / `matchAnyBasicFilters` via `blockHashDisplay`.

`filterHash()` and `filterHeader()` operate on **internal** byte order (raw `SHA256d` output). Filter header columns in the test vectors are also display-order hex; use `displayHashToInternal()` when chaining headers or comparing against vector values.

## Test vectors

Official BIP-158 testnet vectors live in `testdata/bip158/testnet-19.json` (10 blocks). They are generated by [the BIP-158 vector generator](https://github.com/bitcoin/bips/blob/master/bip-0158/gentestvectors.go). `bun test` asserts every row: element extraction, serialized filter bytes, and filter header chain.

## Environments

| Runtime | Entry |
|---|---|
| Bun | `src/index.ts` |
| React Native / Metro | `src/react-native.ts` |
| Browser bundlers | Either entry; browser smoke tests the package API |

Core sources under `src/` use only `Uint8Array` and `@noble/hashes` — no `Buffer`, `node:*`, or Bun APIs.

## Development

```bash
bun run check   # typecheck + unit tests + package smoke tests
```

## Non-goals

- **BIP-157** (client-side filter sync over P2P) is out of scope. This library implements filter construction, matching, and header hashing only — not neutrino-style networking or checkpoint sync.
